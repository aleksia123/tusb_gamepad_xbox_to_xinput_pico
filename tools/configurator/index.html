1 · Put the board in config mode

Unplug the board and plug it back in. Every real power-on starts in config mode: it enumerates as a USB serial port instead of an XInput pad. No jumper, no soldering, no button combo. Click Connect and pick that port within about 5 seconds - connecting sends HELLO, which cancels the timer for the rest of the session. Miss the window and the board reboots itself into normal pad operation; unplug and replug to get another one.

When you are done, click Switch to Xbox mode, or just unplug it.

The RUN/reset button does not enter config mode - it comes straight back up as a controller. That is deliberate: a reset mid-game should not cost you the grace window. Only a real power cycle starts a config session.

Optional, for a long editing session: ground GP29 (a header pin on the Waveshare RP2350-USB-A, active low) before plugging in and the 5-second timer is suspended entirely. Nothing to solder, and the normal flow above needs no wiring at all.

Configuration cannot happen while the board is acting as a pad: Windows binds the dongle's single USB interface to its in-box xusb22.sys XInput driver, which claims it exclusively, so no browser page can open it. Hence the separate boot mode.

2 · Profile slot

During normal operation, hold Back and tap DPad-Up / DPad-Down on the pad to cycle slots live. That is RAM-only: on the next power-cycle the slot marked "boot into this slot" wins.
